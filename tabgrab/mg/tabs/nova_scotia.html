I listened to this song and enjoyed it, so I thought I’d learn how to play it. Saddened as I was when I discovered that there was no tab for it already, I thought that I’d attempt to make one. This is the best I could come up with. There’s not much of a pattern to the song.

Read the following text. It’s important because I tabbed this abmormally.

This is the first tab that I’ve ever made, so it might not be in the proper syntax for tabs. Each “-” is not a beat, and each note is not a one beat either. They could be less or more. I did this in a very strange manner. Sorry. Keep in mind that there are 8 beats in each measure here, no matter what it looks like.
