Play the F from 1st string to 6th: 0 - 1 - 2 - 3 - 0 - 0

In this song, Damien lifts his middle finger frequently off the fourth string on the second fret and strums the chord from 1st string to 6th: 0 - 1 - 0 - 0 - 3 - 0
He does this especially at the end of each line and in the Intro.
